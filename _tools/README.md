# Служебные скрипты сайта asyanova.ru

Не часть сайта: инструменты, которыми собирались страницы. Пути внутри — `/home/claude/asya-nova-site` (рабочая папка), при необходимости поменять.

| Скрипт | Что делает | Можно запускать? |
|---|---|---|
| `build_pressa.py` | Раздел «Пресса» (/pressa/, /pressa/socseti/, /pressa/redlily/) и блоки «О песне пишут» на страницах песен. Материалы — список `ITEMS`, радио — `RADIO`. | Да, основной способ добавлять публикации |
| `build_media.py` | Раздел «Медиа» (/media/, альбомы /media/foto/*/), переадресация /fanatam/ → /media/#skachat, sitemap | Да |
| `lyrics_pdf.py` | PDF с текстами песен (files/fans/tekst-*.pdf) из страниц песен | Да |
| `tag_tracks.py` | ID3-теги для mp3 в files/ | Да |
| `site_build.py` (+ `shared.py`, `songs.py`, `song_seo.py`, `contest_page.py`, `merch_data.py`, `comic_merch.py`) | Старый генератор всего сайта | **НЕТ** — с 9 ноября страницы правятся напрямую в HTML (главная, «Брендам», «Организаторам», «СМИ», кейсы, меню, цели). Запуск затрёт эти правки. Использовать только как справочник по данным песен. |

После правок CSS/JS — обновить `?v=` (md5 первых 8 символов) во всех HTML.
